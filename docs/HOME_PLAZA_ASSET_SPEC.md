# Home 광장 — 배경 에셋 업로드 가이드

오너가 직접 그릴/준비할 **아이소메트릭 룸(또는 거리) 배경 1장** 스펙이다.  
구현 전에 이 파일을 맞춰 주면 코딩 단계에서 바로 붙일 수 있다.

---

## 권장 해상도

사이트 메인 창 콘텐츠 폭이 약 **800px**이므로:

| 용도 | 픽셀 | 비고 |
|------|------|------|
| **권장 (1×)** | **800 × 480** ~ **800 × 520** | 가로형 한 장. 가장 무난 |
| **레티나 (2×)** | **1600 × 960** (~1600 × 1040) | 선명도↑. 표시는 800폭에 `image-rendering: pixelated`로 축소 |

- 세로가 너무 길면(예: 800×900) 창 안에서 스크롤·말풍선 밀도가 나빠진다. **가로 ≥ 세로**를 권장.
- 정사각(800×800)도 가능하지만, 위아래 여백이 커질 수 있다.

---

## 포맷

- **PNG** 권장 (픽셀 아트·가장자리 선명)
- JPG 허용 (사진형·용량 작을 때). 품질 높게
- **GIF 비권장** (용량·애니메이션 불필요)
- 파일명 예: `plaza_bg.png` / `plaza_bg@2x.png`

업로드 위치(구현 시): Supabase Storage `Image/...` 또는 `public/` — 코딩 단계에서 확정.

---

## 구도 체크리스트

캐릭터가 **서기**로 배치되므로:

- [ ] **바닥(지면)이 화면 중·하단에 넓게** 보인다
- [ ] 천장·하늘만 크고 바닥이 좁지 않다
- [ ] 아이소 원근이 한 방향으로 일정하다 (광장이 “평평한 무대”로 읽힘)
- [ ] 캐릭터·말풍선이 올라갈 **빈 바닥 영역**이 충분히 있다
- [ ] 중요 소품이 화면 중앙을 과도하게 가리지 않는다 (스팟 여유)

대략 바닥이 이미지 높이의 **40% 이상**이면 배치하기 좋다.

---

## 톤

- 픽셀 / 저해상도 아이소 OK (Web 1.0·Classic 홈피와 맞춤)
- 모던 실사·유리질감·네온 글로우 배경은 피한다 ([헌법](../CONSTITUTION.md))

## 배경 확정본

- 파일: `public/plaza/plaza_bg.png`
- 실제 크기: **800 × 520** (스펙과 일치)
- 스케일 기준(이 배경 기준): 바 스툴 좌석 높이 ≈ 45–50px, 의자 등받이 ≈ 55px

---

## 캐릭터 스프라이트 (오너 제작 가이드)

MVP는 **서기 1종** (투명 PNG). 이 배경(800×520)과 **1:1 픽셀**로 맞출 것.

| 항목 | 권장 |
|------|------|
| **캔버스** | **64 × 64** px (여백 포함) |
| **캐릭터 실루엣 높이** | 약 **56–64** px (머리~발). 바 스툴보다 조금 크게 |
| **포즈** | 정면 또는 ¾ 서기. 발은 캔버스 **하단**에 붙이기 (배치 기준점) |
| **여백** | 좌우 2–4px. 말풍선은 코드가 머리 위에 붙임 |
| **포맷** | PNG, **투명 배경**, 팔레트 제한 OK |
| **2× (선택)** | **128 × 128** — 표시 시 64로 축소 + `pixelated` |

너무 작으면(32×32) 바·의자에 비해 점이 되고, 너무 크면(96+) 방을 가린다.  
여러 방향(좌/우)은 나중. 지금은 **한 장**이면 된다.

파일명 예: `avatar_stand.png` → `public/plaza/avatar_stand.png`

**현재:** `public/plaza/avatar_stand.png`에 **64×64 더미**가 들어가 있음. 최종 스프라이트로 **같은 경로·같은 파일명**으로 덮어쓰면 코드 수정 없이 교체된다.
